# dsh-workspace-view

DSH Web 客户端的全宽「工作区总览」插件：把工作区收进可自建分组、带配色的卡片里，一眼看清每个项目最近在做什么，点会话就能直接进入。

## 功能

- **全宽总览页**：跨工作区的「最近活动」，加上每个工作区一张卡片；卡片显示最近 3 条会话、相对时间和运行/等待/未读状态。
- **自建分组**：新建、就地改名、上移下移、删除；工作区可拖进分组，也可从卡片菜单移动。
- **分组配色**：冷调、暖调各 5 色，共 10 色；新分组自动领一个未占用的颜色，随时可改。
- **搜索**：按工作区名、路径、会话标题过滤。
- **直接进入**：点会话回到对话界面并打开它；卡片上可直接在该工作区开新会话。

## 安装

### 1. 打包

仓库的 `files` 白名单只含运行所需文件（`index.js`、`client.js`、`cordis.patch.yml`、`icon.svg`、README、LICENSE），打包不会带进 `test/`、`docs/`。

```bash
npm pack
# 生成 dsh-workspace-view-0.1.0.tgz
```

### 2. 装入 profile

```bash
# 用刚打好的包
dsh plugin --profile web add ./dsh-workspace-view-0.1.0.tgz

# 或者直接从 GitHub 安装
dsh plugin --profile web add github:Attack825/dsh-workspace-view
```

`dsh plugin --profile <name> <pnpm args>` 会把参数转发给该 profile 目录下的 pnpm；带 `dsh.bundle` 的包在安装后自动加入组合包列表。

重启 `dsh web`（已开着的页面刷新一次）后，侧栏导航区会多出一行「工作区总览」，点开即是新页面。

Desktop 客户端不走 npm CLI（`desktop` profile 由客户端自己管理），在「插件」页添加同一个包名或 GitHub 地址即可。

## 使用

页面顶部是跨所有工作区的「最近活动」，最多 5 条，按最近更新时间倒序；下面按分组排列工作区卡片，组内也按最近活动倒序。

新建分组在右上角。分组头：点箭头折叠、双击标题改名、拖 `⠿` 调整分组顺序、`⋯` 菜单里可改名、上移、下移、改颜色、删除分组（只解散分组，工作区回到「未分组」）。

归组有两种方式：把卡片直接拖到分组上，或用卡片右上角 `⋯ → 移动到分组`；拖回「未分组」即移出。分组颜色在 `⋯ → 分组颜色` 里选，色板按冷调/暖调分两行。

卡片最多显示 3 条会话，多余的收在「展开全部 N 条」里；置顶会话排在最前。点会话会离开本页、进入对话并打开该会话；卡片上的「＋」在该工作区开一个新会话。

分组、颜色和折叠状态存在浏览器 localStorage，刷新和重启都还在；清空站点数据会回到全部未分组。
