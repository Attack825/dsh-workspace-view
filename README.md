# dsh-workspace-view

**一句话：** DSH Web 客户端的全宽「工作区总览」插件——把工作区收进可自建分组、带配色的卡片里，一眼看清每个项目最近在做什么，点会话就能直接进入。

DSH 自带的左侧栏只有 264–420px 宽，工作区默认全部展开，折叠和重命名还藏在悬停里；项目一多，就只能靠滚轮找人。这个插件不修改官方侧栏，而是在侧栏图标栏加一个入口，用主区域整块宽度做一页总览。

## 功能

- **全宽总览页**：跨工作区的「最近活动」+ 每个工作区一张卡片，卡片直接显示最近 3 条会话、相对时间和运行/等待/未读状态。
- **自建分组**：新建分组、就地改名、上移下移、删除；把卡片拖进分组，或走卡片「⋯ → 移动到分组」。
- **两组配色，共 10 色**：冷调与暖调各 5 色（取自用户提供的参考配色），新分组依次领色，8px 色点 + 卡片顶部 2px 细线 + 6% 同色底。
- **随意改色**：分组「⋯ → 分组颜色」里点圆点即可，色板按冷调/暖调分两行。
- **搜索**：按工作区名、路径、会话标题过滤；过滤时「最近活动」同步收窄。
- **进入即离开**：点会话回到对话界面并打开该会话；卡片「＋」直接在该工作区开新会话。
- **刷新不丢**：分组、配色、折叠状态存在浏览器 localStorage；清空后回落为「全部未分组」，不报错。

## 安装

前提：DSH Web 或 Desktop，客户端版本 `0.2.x`。

**方式一：插件页安装（推荐）**

在 DSH 的「插件」页添加包，spec 填本仓库地址：

```
github:Attack825/dsh-workspace-view
```

**方式二：本地目录安装**

把仓库克隆到本地，然后在插件页添加包并选择该目录；或在会话里让 Agent 用 `plugin_manager` 的 `install_bundle`，target 填包目录绝对路径。

安装后**刷新页面**（Ctrl+R）。侧栏导航区会出现一行「工作区总览」，点开即是新页面。

- 分组头：箭头折叠、双击标题改名、`⠿` 拖动排序、`⋯` 改名/上移/下移/分组颜色/删除。
- 卡片：拖到分组或「未分组」即可归组；`＋` 新会话，`⋯` 移动到分组。
- 默认排序：组内卡片按最近活动降序。

## 设计上的几条边界

- **不改官方侧栏**：主区域新增面板，官方的工作区列表、搜索、归档、重命名全部照旧。
- **只读展示**：本页不做工作区改名、删除、归档、置顶，这些仍在侧栏完成，避免和官方那套易碎的交互抢地盘。
- **会话可见性**：非归档、非空白、且来源不是 subagent 的会话才计入列表与计数（与官方侧栏一致）。
- **本地偏好**：分组、配色、折叠存在 `localStorage` 的 `dsh-workspace-view/groups/v1`，换浏览器或清站点数据会丢，这是有意的取舍。
- **无 Host 逻辑**：`index.js` 是空实现，不注册服务、命令或工具；所有数据来自槽位标准 props。

## 开发

```bash
node --test test/state.test.mjs
```

测试覆盖：分组状态规范化（坏数据、重复标题、未知颜色回落）、增删改移、自动取色与循环、会话可见谓词、卡片排序与计数、搜索匹配、相对时间，以及用假 hooks 把整页组件树真跑一遍的渲染冒烟测试。

目录：

```
client.js                    浏览器半身：面板图标、页面、分组状态、样式
index.js                     Host 半身：空实现
cordis.patch.yml             bundle patch（insert 一行）
package.json                 dsh.bundle / dsh.client 声明
docs/superpowers/specs/      设计稿
docs/plans/                  实现计划
test/state.test.mjs          纯逻辑与渲染测试
```
